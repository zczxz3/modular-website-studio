# 可导入示例

[第一次做网站](../docs/guides/first-website.md) · [工程与模块格式](../docs/formats.md)

| 路径 | 用途 | 怎样使用 |
| --- | --- | --- |
| `basic/` | 普通 HTML/CSS/JS 网站，验证源码导入与独立导出 | 在工作台导入文件夹或打成 ZIP 后导入网站 |
| `modules/module.json` | 静态模块协议的最小示例 | 将该文件放在 ZIP 根目录，用「安装模块 ZIP」加载 |

完整中文作品集位于 `src/templates/portfolio/`，通过首页「使用这个模板」创建；它不是要求新手逐个拼接的文件清单。内置 31 个组件的源文件位于 `src/resources/website-assets-library/`，直接从工作台组件面板使用。

示例属于开发与学习输入。自己的作品请通过工作台下载 `.mws.json` 工程备份，或导出完整网站。
