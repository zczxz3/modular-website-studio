# 首个中文作品集：五人可用性验收

状态：**方案已准备，尚未招募或执行，暂无学生结果。** 自动化测试不能替代首次使用者的观察。

## 目标与准备

邀请 5 位从未使用本平台的同学，独立完成同一条创作流程。使用匿名编号 S01–S05，不记录姓名、联系方式等无关信息。每人准备一张横图、一张竖图和一句作品介绍；可以使用不含个人信息的练习图片。

记录本次实际构建的提交 SHA、浏览器版本、操作系统、起止时间及入口地址。入口尚未发布时写明“本地测试构建”，不要向参与者声称已经上线。设备使用桌面浏览器；390px 是作品预览宽度，不是手机端编辑能力的证明。

主持人只读任务，不演示点击位置，不解释文件扩展名。参与者可说出正在寻找什么；卡住时先记录，再提供帮助，并区分独立完成和帮助后完成。经参与者同意再录屏；文字观察已经足够执行本方案。

## 给参与者的任务

> 请从首页制作一个自己的作品集：写上你的名字和介绍，换上两张作品图片，调换它们的顺序，给主标题加一个淡入效果。查看手机尺寸下的效果，保存一份明天还能继续修改的版本，再导出一份可以发给别人独立打开的网站。请按自己的理解操作。

不要在任务开始时告诉参与者“工程文件”和“网站文件”分别是哪一个。任务完成后再询问判断依据。

| 排作品 | 是否理解拖动；能否发现撤销 | 两张作品顺序改变，撤销/重做结果正确，其他内容不丢失 |
| 加特效 | 选中标题后是否发现适用效果；快慢和强弱能否理解 | 淡入可重播、移除、撤销；导出中仍有效；减少动态效果时内容可见 |

| 保存与交付 | 最终点了哪个按钮、拿到了哪些文件 | 能解释哪个继续编辑、哪个发给别人；独立打开网站不需要 Studio |
| 第二天恢复 | 是否找到自己的版本；是否需要重新找图片或从模板重做 | 同浏览器恢复本机草稿；再用下载的可编辑工程在无历史记录窗口恢复 |

## 导出与恢复的客观核验

1. 记录参与者实际下载的文件名，不只看按钮点击成功。可编辑工程应能恢复文字、图片、顺序和效果；导出网站应能独立运行。
2. 完整网站 ZIP 解压到新目录，断网后直接打开 `index.html`，检查首页、作品详情页、图片和返回链接；同时用独立静态服务器检查相同文件。两种运行方式分别记录。
3. 若选择单页 HTML，检查该页实际可独立打开；有其他页面链接时应看到明确的完整网站导出说明，不把单页当成包含全站的交付。
4. 第二天先让参与者自行恢复，不提示位置。之后才补做无历史记录窗口的工程导入，以证明文件没有依赖当前浏览器记录。无痕窗口关闭后本机草稿通常不会保留，不作为持久草稿测试环境。
5. 若出现错误、丢图、恢复到旧版本或错误文件用途判断，保留脱敏后的复现步骤和实际结果，不将“帮助后成功”记为独立成功。
