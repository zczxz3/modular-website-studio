## 两个仓库各做什么

| 仓库 | 负责 | 不在本轮承担 |
| --- | --- | --- |
| [modular-website-studio](https://github.com/zczxz3/modular-website-studio) | 模板起步、组件选择、可视化编辑、素材/主题/动效、草稿/工程和独立网站导出 | 替代整个前端构建生态 |
| [website-assets](https://github.com/zczxz3/website-assets) | 组件研究、效果演示、静态模块源码、固定版本发行与来源记录 | 自动改变 Studio 中已经保存的工程 |

Studio 已内置上游固定版本的 31 个静态模块，和既有组件/区块共 41 个目录项。组件库不是“仅留接口”；继续预留的是远程同步、升级和任意 JS 生命周期，详见 [资源协议](resource-sync.md)。

## 当前代码和入口

| 位置 | 用途 |
| --- | --- |
| `main` | 已整合的可运行 alpha 源码；普通使用和开发从这里开始 |
| GitHub Releases | 带启动脚本的使用版、源码包和校验清单 |
| `src/` | 按界面、内核、画布、模板、资源和第三方运行库组织，[查看源码地图](../src/README.md) |
| `docs/guides/` | 面向使用者的连续操作说明 |
| `docs/development/` | 面向开发者的代码入口和编辑约束 |
| `docs/archive/` | 早期分支与上游调查快照 |
| `tests/`、`e2e/` | 源码回归和浏览器回归 |
| `scripts/` | 资源再生成、检查、静态服务和发行包 |

旧开发分支保留其历史用途，不要求新手切换分支、下载多个 JSON 或手工拼接目录。主分支完整功能基线为 `0e182ef`（[PR #2](https://github.com/zczxz3/modular-website-studio/pull/2)）；新整理见 [更新日志](../CHANGELOG.md)。

## 统一数量和状态

- **可添加**：已接入插入、保存和独立导出路径的静态组件。
- **可体验**：有独立演示，不能据此承诺已安装进 Studio。
- **研究参考**：设计或技术来源，不计入当前组件数。
- 模板、区块、组件、素材和特效分别描述；存在实现重合时明确说明。

目前内置 31 个上游模块、7 个工作台组件和 3 个区块；完整中文作品集单独作为模板，AOS/AnimXYZ 作为特效能力，不与组件数量相加。
