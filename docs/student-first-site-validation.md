# 学生的第一个独立网站

本轮在 `d73c326` 之后的本地 `feat/student-first-site` 分支实现；远端和在线发布状态见 [仓库汇总](repository-overview.md)。本页记录工程验收，不替代真实学生试用。

## 可操作流程

1. 开始页点击 **使用模板**，直接选中主标题。在 **你的姓名** 填中文姓名，点击 **应用姓名**；页眉、页脚和模板页面标题一起更新。
2. 点击 **换作品封面** 定位第一件作品。在右侧上传横图，再选第二件作品上传竖图；设置 **裁切位置** 和 **图片说明**。也可从素材选择或 **使用纯色封面**。
3. 从页面列表选作品，或在图片上点击 **选中作品卡**，拖动选框手柄排序。图片、文字和详情链接作为一个整体移动，可一次撤销。
4. 点击 **给标题加特效** 回到主标题；应用淡入，用 **触发时机／快慢／强弱** 调整，重播或移除。标题描边、封面悬停缩放、按钮悬停描边、区块磨砂按选中对象提供，均随网站保存。
5. 点击 **390px 手机预览**。编辑、预览与页面切换都在同一工程内完成，无需下载文件衔接。
6. 有效修改延迟保存至本浏览器；观察底栏草稿状态，也可手动 **保存草稿**。刷新后从首页的 **最近草稿** 继续。
7. **下载可编辑工程** 获取 `.mws.json` 备份；换浏览器时用 **打开项目文件**。**导出网站** 中选择 **下载网站 ZIP**，解压并打开 `index.html`，四页网站、图片、样式和效果一起保留。

## 数据与边界

姓名只修改 `data-mws-profile` 明确标记的叶子元素，不替换正文中同名内容。关联封面用 `data-mws-cover`，同一作品的首页和详情页同步图片、裁切与说明；仅共享图片 URL 的无关元素不会受影响。上传新图片清空旧说明，等待用户补充正确描述。

复制作品卡后封面拥有独立关联键，避免修改副本时改变原作品。复制保留原链接，不自动复制详情页面；若要创建新的详情页，需要后续页面管理能力或高级编辑。

草稿仅写一份最近项目快照，不在旧保存键重复存整份图片。无效代码草稿不自动保存；配额或访问失败保留旧快照并提示下载工程。浏览器清理、突然崩溃和未完成的下载不能视为可靠备份；保存状态与工程文件仍是恢复依据。

CSS 效果不写入布局的 `translate` 或 `transform`。模板基础按钮悬停改为阴影反馈，避免覆盖拖动位置。外部 JS/WebGL 效果仍需适配，素材仓库自动接入保持预留状态。

## 自动化覆盖

| 文件 | 检查内容 |
| --- | --- |
| `tests/profile.test.ts` | 中文/特殊字符、跨页定点修改、源码身份、撤销、保存导出重开 |
| `tests/covers.test.ts` | 封面同步与独立性、裁切/说明、纯色资源冲突、页面链接、保存导出 |
| `tests/effects.test.ts` | 适用对象、布局属性保留、共享样式、复制和 HTML 重开 |
| `tests/drafts.test.ts` | 单份快照、配额失败保留原值、无效工程拒绝、双按钮独立样式 |
| `tests/reconcile.test.ts` | 安全投影 `lang/dir`；只有明确的新手导航才滚动到目标 |
| `e2e/student-first-site.spec.ts` | 真实横/竖 PNG 上传、整卡排序、中文名、390px、草稿刷新恢复、工程重开、ZIP 解压后 `file://` 离线打开；悬停不改变拖动位置 |
